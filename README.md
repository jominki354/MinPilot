# MinPilot

SunnyPilot 기반의 Custom Openpilot Fork (C2 Platform)

## 주요 기능

## 주요 기능 (설정 메뉴 가이드)

### 1. 시스템 설정
- **조용한 주행**: 경고음을 최소화하여 동승자를 배려합니다.
- **빠른 부팅**: 시동 직후 바로 사용할 수 있도록 부팅 속도를 최적화합니다.
- **저사양 모드**: 로깅/녹화/GPS 등 백그라운드 프로세스를 꺼서 발열을 줄이고 성능을 확보합니다.
- **데이터 절약 모드**: 주행 로그 업로드를 차단하여 데이터를 절약합니다. (지도 기능 사용 시 해제 필요)
- **배터리 방전 방지**: 시동을 끄면 장치도 즉시 종료되도록 강제합니다.

### 2. MADS (상시 조향)
- **독립형 조향 보조**: 크루즈(ACC)와 상관없이 차선 유지 기능만 단독으로 사용할 수 있습니다.
- **크루즈 연동**: 핸들의 SET/RES 버튼으로 손쉽게 상시 조향을 켜고 끌 수 있습니다.
- **핸들 파지 감지**: 운전자가 핸들을 잡고 있는지 모니터링하여 주의를 줍니다.

### 3. 속도 제어
- **제한 속도 연동**: 지도 데이터 기반으로 규정 속도에 맞춰 크루즈 설정 속도를 자동 조절합니다.
- **커브 감속 (지도/비전)**: 급커브 진입 시 지도 데이터나 카메라 시야를 분석해 미리 속도를 줄입니다.
- **속도 조절 간격**: 크루즈 속도 변경 단위를 운전자 취향대로 설정할 수 있습니다.

### 4. 차선 변경
- **도로 가장자리 감지 (RED)**: 차선이 없는 곳이나 갓길로의 위험한 차선 변경을 막아줍니다.
- **자동 차선 변경 타이머**: 방향지시등 작동 후 차선 변경 시작까지의 대기 시간을 조절합니다.

### 5. 조향 튜닝
- **동적 차선 모드 (DLP)**: 고속도로/국도 등 주행 환경에 따라 차선 유지 감도를 자동 전환합니다.
- **조향 토크 설정**: 핸들을 돌리는 힘(토크)을 차종별 특성에 맞게 미세 조정할 수 있습니다.
- **가변 조향비**: 속도에 따른 조향비 변화율을 설정하여 고속 주행 안정성을 높입니다.
- **차선 편향 (Offset)**: 차량이 차선 중앙보다 좌/우로 치우쳐 달릴 때 위치를 보정합니다.

### 6. 화면 설정
- **레이더 정보 표시**: 앞차와의 거리, 상대 속도 정보를 시인성 좋은 박스 형태로 표시합니다.
- **디버그 UI**: 개발자용 상세 수치나 로그 저장 버튼을 화면에 띄울 수 있습니다.
- **화면 밝기/끄기**: 주행 중 화면 밝기를 조절하거나 일정 시간 후 자동으로 끕니다.

### 7. 안전운전 도우미 (CarrotMan)
- **과속 단속 경고**: 고정식/이동식/구간 단속 카메라 정보를 받아 사전에 경고하고 감속합니다.
- **방지턱 감속**: 전방에 과속 방지턱이 있으면 부드럽게 속도를 줄입니다.
- **스쿨존 알림**: 어린이 보호 구역 진입 시 주의 알림을 띄웁니다.

### 8. 기타 편의 (장치 메뉴)
- **설정 초기화**: 모든 커스텀 설정을 클릭 한 번으로 기본값으로 되돌립니다.
- **설정 백업/복원**: 내 설정을 서버에 백업하거나 다른 기기에서 불러올 수 있습니다.
- **IP 주소 표시**: 메인 화면 사이드바에서 현재 기기의 네트워크 연결 상태를 바로 확인합니다.
