# MinPilot

**MinPilot** is a custom fork of openpilot for **Toyota Camry Hybrid 2022**.

## 🚀 Features
- **Localization**: Full Korean UI support.
- **Safety Assistant**: CarrotMan integration (Speed Camera, Bump Alert).
- **Tuning**: Custom steering torque, ratio, and path offset.
- **UI Improvements**: Sidebar IP address, Road Edge Detection visualization.
- **Utilities**: Settings reset, Rlogs analysis tools.

## 📦 Version
- **AgVersion**: 0.8.12 (MinPilot Release)
- **Base**: SunnyPilot / OpenPilot 0.8.12

## 🚗 Supported Vehicles
- **Toyota Camry Hybrid** (2021-2024)
- *Tested on C2 / Black Panda*
