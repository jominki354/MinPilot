# MinPilot Changelog

- **Release**: Initial MinPilot release based on SunnyPilot / OpenPilot 0.8.12.
- **Rebranding**: Fork name changed to MinPilot.
- **Localization**: Full Korean UI support required.
- **New Features**:

  - Sidebar IP Address display.
